PRIVACY POLICY

Privacy

Effective August 29, 2026

Version Replay stores imported and captured webhook fixtures in the vault directory you choose.

CLI data

Configured headers and body fields are redacted before a fixture is written. Encrypted vaults protect fixture contents with AES-256-GCM and a key derived through Argon2id. The passphrase remains in your environment and is not written to the vault.

Network access

Replay accepts loopback destinations only. Other CLI commands do not upload fixture contents. The project has no telemetry client.

Browser sample

The sample comparison runs in this page. It does not send fixture contents to a server. Demo mode does not read or write browser storage.

Website records

The website saves a theme choice outside demo mode. It uses no advertising cookies or behavioral analytics. The hosting provider may process request and security logs under its own retention policy.

Your control

Delete a vault by removing its directory. Clear this site’s storage in your browser to remove the theme choice.

Contact

Use the security guidance in the Version Replay repository on GitHub. Do not include real webhook data.
