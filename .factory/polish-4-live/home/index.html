HOW VERSION REPLAY WORKS

Save, compare, then replay

Use a saved webhook fixture for each provider version.

  1. 01

    Save and redact a fixture

    Import JSON or capture one request on a loopback listener.

    vr import --name payment-failed …
  2. 02

    Compare version changes

    List method, path, header, type, and value changes.

    vr diff --from OLD --to NEW
  3. 03

    Replay it to localhost

    Send either saved request to code running on your machine.

    vr replay --to http://127.0.0.1:3000/hook
